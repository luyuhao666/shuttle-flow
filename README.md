# Shuttle Flow

从己方底线后上方看向对面的羽毛球小游戏。固定透视球场、四向移动、手动挥拍，支持普通练习、人机比赛、专项练习和局域网双人对战。

从 GitHub 获取当前源码：

```powershell
git clone https://github.com/luyuhao666/shuttle-flow.git
cd shuttle-flow
npm.cmd ci
npm.cmd run desktop
```

已经克隆过的项目先保留自己的未提交改动，再拉取最新 main，并运行 `npm.cmd ci` 更新依赖。Windows 游戏内可以直接创建联机房间；Git 仓库存放源码和素材，开发依赖、打包目录与本机测试记录按忽略规则保存。

## 局域网 / Radmin VPN 双人对战（1.1.0）

双方使用同一份新版 Windows 游戏，打开 **Match Mode → LAN Match**（比赛模式 → 局域网对战）。

1. 普通局域网：两台电脑连接同一网络。远程对战：双方先安装并加入同一个 Radmin VPN 网络。
2. 主机点击 **Create room / 创建房间**，默认端口 `3210`，可选择 7 / 15 / 21 分。游戏会自动启动内置服务并显示本机地址。
3. 朋友在 **Join room / 加入房间** 输入主机的 `IP:端口`，例如 `26.12.34.56:3210`。Radmin 对战使用 Radmin VPN 显示的 IP；同一 Wi-Fi 使用对应的本机局域网 IP。
4. 双方点击 **Ready / 准备**，比赛开始。双方都从自己的底线后看球场，键鼠与原单机操作相同。
5. 任一方按 P / Esc 或切换窗口会同步暂停；暂停的一方需自行点击继续。结算后双方准备可再来一局。断线后需要重新创建 / 加入房间。

Windows 询问时，允许游戏通过当前局域网或 VPN 网络的防火墙；无需关闭防火墙。连接失败时核对网络、IP、端口、游戏版本及主机防火墙放行；端口被占用可换一个。电脑需保持开机并运行游戏。无需额外安装 Node.js、购买公网 IP 或配置路由器端口映射。游戏自己的网络会话直连，避免系统网页代理接管 Radmin 地址，不更改 Windows 代理配置。

联机限定两人一对一。主机统一计算球路、触球与比分，保留原移动惯性、起跳、点杀、跳杀及力度规则；短时历史校验与画面平滑用于应对网络延迟。高延迟和抖动仍会影响手感。原有离线练习、人机、教程、存档和双语切换保留。

2026-11-04 已优化网络波动时球和对手的显示连续性，并减少角色绘制时反复分配缓冲区的开销。回球速度、力度、触球判定和主机比赛逻辑保持。双方使用更新后的完整游戏文件夹，可以获得各自客户端上的改善。

源码开发仍可 `npm.cmd run desktop`。`npm.cmd run start:lan` 仍是静态网页服务；Windows 游戏内建房不需要启动它。浏览器可加入已建好的房间，创建房间请使用桌面版。验证入口为 `npm.cmd test`、`npm.cmd run check`、`npm.cmd run verify:lan`；原生双实例检查为 `node scripts/verify-lan.mjs --electron`，发布目录检查再加 `--packaged`。检查使用独立临时存档，原生隐藏窗口通过 QA 帧泵调用原生产更新与绘制函数；不改变正式游戏行为。

### 球场新手教程（2026-10-14）

主菜单面板右下角 **New here? · Tutorial ↗** 进入新手教程，五个主要入口保持。教程使用当前真实球场和角色；不自动弹出，随时可重播。

八课依次学习移动与高远、向左瞄准、吊球、地面进攻、挑球、挡网、平抽和跳杀。每课点击 **Send shuttle** 看真实来球，在接球前自动定格；点击 **Try it** 后可以移动、瞄准和选择球路，来球暂时保持不动。挥拍后恢复飞行，用原接触/球路/越网/出界判定检查回球，落地后才确认课程完成。正常比赛和练习没有这些定格。

跳杀课先手动起跳，在原物理最高点暂停人物和来球，再按进攻操作打出真实跳杀。不是自动起跳或自动挥拍；手机选择 Attack 后点 Jump，再点并松开大击球按钮，键鼠使用 Space / 右键。

**Next lesson** 继续下一课，做错显示原因并用 **Retry shot** 重试同一来球，不自动推进。**Exit** 或暂停菜单的 Exit tutorial 返回主页；帮助/设置打开后保持暂停，继续时保留课程。完整学完后记录本机完成标记，结果页 **Replay Tutorial** 从头重播，教程不计入普通练习最高分。

键鼠与触屏说明分别显示，移动目标与相关触控高亮。桌面提示卡位于球场左上方；手机提示条放球场上方，避免盖住羽毛球，竖屏/横屏均可，手机可先用横屏体验。

166 项自动测试、30/60/120/240fps 完整课程、五尺寸真实浏览器界面和桌面/触屏八课通过；新教程仍待真实手机试玩。截图 `artifacts/tutorial-home-desktop.png`、`tutorial-desktop-move-paused.png`、`tutorial-landscape-jump-apex.png`；报告 `artifacts/tutorial-browser-checks.json`。Windows 文件夹版已同步；旧 ZIP 仍为历史快照。

### 手机双拇指操作（2026-10-14）

左侧固定摇杆支持任意方向移动，松手减速；右侧先选 **Clear / Drop / Attack**，再点大击球按钮，松手时挥拍。按住大按钮左右拖动可瞄准，拖动本身不会挥拍；64px 横向拖动覆盖中心到边侧。**Jump** 独立起跳，跳杀仍需在最高点附近手动击球，没有自动跑位、自动接球或自动跳杀。

大按钮随来球显示实际动作：Clear / Lift、Drop / Block、Smash / Jump smash / Drive。接杀时，Clear 选挑球、Drop 选挡网、Attack 选低位平抽。球路选择在后续来球中保留，新开局恢复 Clear。轮到发球时选择 **Long / Short**，松开摇杆停稳后点大按钮；发球期间隐藏 Drop 并停用 Jump。

默认沿用设置中的各球种力度。**Power · Auto** 展开 Light / Medium / Strong 和 Use defaults，临时选档仅影响当前来球，下一球恢复默认。取消触摸、丢失捕获、暂停、切后台、旋转屏幕和结束比赛会清理按住状态，避免持续跑动或补发旧挥拍。桌面键盘/鼠标操作保持。

竖屏控制区位于球场下方，横屏在球场两侧，按钮至少 44px。手机第一次竖屏进入会建议旋转，可继续竖屏；旋转后点 **Play in landscape** 开始。游玩中换方向会暂停，点 **Resume** 继续；不会自动开始或补发之前按住的动作。

横屏两侧操作区已缩窄，球场加宽 64px，大击球按钮加高，顶部工具按钮扩大。横屏瞄准轨道显示当前方向；按住时显示 **Release to hit · Drag to aim**。小高度屏幕和教程自动使用紧凑按钮排列。九种尺寸的浏览器真实双指输入、练习/比赛布局与完整小横屏教程已检查；新版横屏仍待真机试玩。预览见 `artifacts/mobile-controls-landscape-match.png`、`artifacts/mobile-controls-landscape-aiming.png` 和 `artifacts/tutorial-short-landscape-jump-apex.png`。

电脑和手机连接同一 Wi-Fi 时，在项目目录运行：

```powershell
npm.cmd run start:lan
```

手机浏览器打开终端打印的 **Phone on the same Wi-Fi** 地址即可试玩，可先试横屏。默认 `npm start` 仍只供本机访问；这是现有单机游戏的局域网网页入口，不是玩家联机对战，也不是微信小游戏。用户已在真实手机上打开游戏，反馈竖屏操作较难受；触控手感仍需迭代。若校园网设备无法互访，可换同一热点排查。PowerShell 拦截 npm.ps1 时使用 npm.cmd，不必更改系统执行策略。

## 操作与规则

开始界面使用本地像素动漫封面，展示练习模式、比赛模式、专项练习、个性化和游戏设置五个入口；所有入口使用相同的实色按钮和字号。点击模式进入独立准备界面：比赛可选分值、实力与打法，专项可选内容、速度与长度；设置好后点击底部开始按钮。配置内容可以独立滚动，开始按钮固定在底部。点击“返回”或按 Esc 回到封面。进入游戏后切换至专注球场。封面与比赛设置预览见 `artifacts/home-navigation-desktop.jpg`、`artifacts/mode-setup-match-mobile.jpg`。

开始按钮上方显示英文配置摘要，例如“15 pts · Casual · Rally”，与三组选项实时联动。选中项为柠檬绿底与深色文字，无勾选图标；普通选项高 44px，主按钮高 52px，说明和底部操作保持留白。

游戏设置独立分为“音效”和“默认击球力度”两个区域：音量支持 0～100%，0 为静音，另有音效开关和击球试听；默认力度可分别设置高远、吊球、杀球。音量同时控制真实录音与合成提示音，保存后重新打开继续使用。桌面并排展示设置，手机竖屏上下排列；底部“完成并返回”固定可见。顶部 ? 打开操作帮助，⚙ 随时进入设置；游戏中打开会暂停，关闭后回到原来的界面。设置预览见 `artifacts/game-settings-desktop.jpg`、`artifacts/game-settings-mobile.jpg`。

两个设置区域可以分别恢复默认：音效恢复到开启、100% 音量；力度恢复到高远重、吊球轻、杀球中，各自不影响另一组。修改成功后短暂显示“✓ 已保存”；浏览器无法保存时显示“仅本次有效”。游戏内突出比赛比分和实际触球提示，默认力度、辅助说明与预计落点采用较淡的显示，临时力度仍会强调。

### 个性化

封面、游戏设置和暂停面板均可进入个性化界面。当前提供经典绿、樱花粉、晴空蓝、暮光紫四种球场，墙面、场外地面与场内地板协调换色；边线、球网与触球提示保持清晰。选择后立即应用，预览使用游戏的实际绘制结果，并自动保存到浏览器。返回或 Esc 回到进入前的界面，游戏中修改会保持暂停。

个性化新增“球衣配色”：先选玩家或人机，再分别修改球衣主色和条纹颜色，正背面及球场预览立即同步，并自动保存。条纹默认自动采用与主色有区别的配色；手动选择后随主色修改保持不变，点击条纹色块组中的“自动”恢复联动。领口、袖口、球衣样式保持，浅色球衣的背号自动变深以方便辨认；袜子、短裤、护具、鞋子和另一个角色不会被连带换色。“恢复原配色”仅恢复当前角色，玩家回到蓝/浅蓝、人机回到米色/棕色，不清空球场与落点颜色。

球拍外观已提供样式、大小和预设配色，见文末“球拍外观”。配色与自动搭配规则位于 `appearance.js`，换色只修改运行时材质，不改写 GLB 的原始配色；独立模型预览仍展示原配色。球衣界面见 `artifacts/personalization-jersey-{desktop,mobile,landscape}.png` 和 `artifacts/jersey-colors-preview.png`，四种球场原生图为 `artifacts/court-style-{classic,sakura,sky,dusk}.png`。

个性化内可分别自定义“来球落点”和“回球瞄准”颜色：点击已有预设色块直接应用、预览并保存，切换球场仍保留所选颜色。“恢复自动配色”让来球落点跟随球场、回球瞄准跟随球种；粉色场地默认用深蓝落点和白色外沿。自选颜色自动配上深色或白色外沿，接球时机仍使用原有的状态颜色，出界/下网仍用警示色。不同大小、虚实线和十字继续区分预计落点与实际接球位置。界面见 `artifacts/personalization-colors-hidpi-desktop.png` 和 `artifacts/personalization-colors-hidpi-mobile.png`。

球场和预览按显示尺寸与屏幕像素密度绘制，高分屏、浏览器缩放和手机旋转时同步更新画布与场景缓存。相机逻辑仍为 1200×720，不改变移动、触球或瞄准规则。按最新反馈，落点文字使用透明背景，不加黑色底牌、文字描边或阴影；16px 基准字号与像素对齐保持清晰，字色跟随球场选择高对比的深浅颜色，接球提示避让角色和预计落点。其他界面采用系统 UI 字体，按钮/说明使用较轻字重、标题保持层次，增强文字对比度，去掉模糊文字阴影；游戏状态提示也恢复透明。桌面击球键位提示移至球场底部空白区域，窄屏隐藏这组键盘提示。边线稍加粗、使用实色，并删去球馆装饰性小字，主招牌在竖屏保持文字比例。效果见 `artifacts/game-text-transparent-{desktop,mobile,landscape}.png`（DPR 2/3 高清截图）、`settings-text-desktop.png` 和 `home-text-desktop.png`。

### 模式

- 练习模式可并列选择“喂球练习”和“落点挑战”。喂球练习：人机单个喂球，不限球数、失误后继续练习；保留 Perfect / Good、连击、练习分数及本地最高分。顶部显示实际练习时长（暂停不计时），点击球场右上方的大按钮“结束并总结”或暂停菜单中的“结束并查看总结”后结算。
- 落点挑战：练习模式中选择“落点挑战”，可练综合落点、后场或网前，选择 20 球或不限球数。对面标出当前目标区，鼠标横向瞄准，球种与 1 / 2 / 3 档决定远近；网前可尝试轻档吊球，后场可尝试重档高远。稳定喂球，目标在每球结束后轮换；只有球实际合法落地才判定命中，目标区 +100、虚线中心区 +150，漏接/出界/下网不得分。20 球自动结算，无限模式点击“结束并总结”；总结显示命中率、中心命中、连续命中和失误原因。挑战分数不影响喂球练习最高分。
- 比赛模式：开始前选择 7 / 15 / 21 分制和休闲 / 标准 / 高手三档人机实力。每个回合计 1 分。若在目标分前一分打平，需要领先 2 分才获胜；7 / 15 / 21 分制分别在 11 / 21 / 30 分封顶。击球评价和跳杀不直接增加比分，只有赢下整个回合才得分。
- 开局人机发球，之后由上一分的获胜者发球。轮到你发球时，松开方向键停稳，左键发高远球，右键发小球；触屏选择 Long 或 Short，再点大击球按钮。双方每分之后回到正确的发球 / 接发区域。
- 单打发球区：以发球方自己的比分为准，0 / 偶数分从自身右区发球，奇数分从自身左区发球。对手视角的右区在屏幕左边；双方站在斜对角区域。发球区从前发球线到后底线，使用单打内侧边线，不使用双打后发球线。
- 发球前高亮双方区域，自动安排站位；可在正确区域内调整位置，但脚不能越区或踩线，也不能起跳。挥拍发球时锁定双脚，触球后立即恢复整个半场的移动与跳跃。人机会等你松开方向键、停稳后发球。
- 发球只落入斜对角接发区；鼠标指向其他区域时自动限制到合法区域内，瞄准标记同步显示实际发球落点。高远发球落向后场，小球采用向上越网的低弧线，落在前发球线后约 .09 的位置；瞄准标记会按所选发球球路显示实际落点。普通回球可连续调整横向方向，不受发球区限制。
- 普通回球按实际落点判定：落在单打边线或底线上算界内，超出界线算出界；越网时高度不足算下网。练习模式失误中断连击且该拍不加分，随后继续喂球；比赛模式失误由人机得 1 分。人机会判断出界球并放弃追球。发球仍按原有斜线发球区限制，力度固定。
- 发球区域参考 BWF《Laws of Badminton》9.1、10.1 与球场图 A：[规则 PDF（丹麦羽毛球协会托管）](https://badminton.dk/wp-content/uploads/2025/11/Section-4.1-Laws-of-Badminton-26-April-2025-V5.0-1-.pdf)。7 分制及其 11 分封顶是小游戏设定；15 / 21 分追分封顶分别参照 [BWF 15 分替代赛制](https://system.bwfbadminton.com/documents/folder_1_81/Statutes/CHAPTER-4---RULES-OF-THE-GAME/Section%204.1.4%20-%20Alternative%20Laws%20of%20Badminton.pdf) 和 [BWF 21 分规则](https://system.bwfbadminton.com/documents/folder_1_81/Regulations/Simplified-Rules/Simplified%20Rules%20of%20Badminton%20-%20Dec%202015.pdf)，一局制仍是游戏设定。
- 人机按球的实时位置和高度追球，具有反应时间、移动速度和接球范围限制；高球保留下降阶段的接触窗口，低球可在路径上拦截。它会按你的站位选择高远、吊网前、下压球或有条件的杀球，适合的高球也可能提前起跳打跳杀。接不到则你得分；你漏接则人机得分。
- 三档实力现已整体上调：Casual（休闲）沿用原标准，Standard（标准）沿用原高手，Expert（高手）为新增强化档，提升脚步、接杀和反击稳定性。三档均需要实际跑到球旁才能回击；高手在偏远站位或连续被调动时仍会漏球。
- 比赛结算显示最终比分、最长回合、跳杀与回球次数。比赛分数不会覆盖练习最高分。
- 人机击球后会带着惯性回到合适的防守位置：打出高远回位稍靠后，打出网前球则稍靠前。连续追到边角、急停换向或重心未稳会降低回球质量，减少进攻、放慢回球、缩短后场深度或让网前球浮起；被动时优先挑球缓解压力。它也会观察你被上一球调到前场或后场，增加下一拍反方向调动的倾向。比赛右侧显示回位、追球或被动回球状态。
- 同一组合法点杀/跳杀、不同站位与移动状态的模拟中，三档点杀回球率约为 53% / 89% / 95%，跳杀约为 33% / 58% / 65%；这是固定测试球路的结果，不代表真人比赛胜率。四种打法继续独立于难度。
- 比赛菜单可另选人机打法：均衡（默认）、进攻、防守、拉吊。打法和实力分开：进攻型更常下压、杀球、起跳抢攻与平抽反击；防守型更偏深挑和稳健高远；拉吊型更常用后场高远和网前吊球连续前后调动。进攻回位靠前，防守靠后；拉吊即使你回到中场也会继续拉深吊短。四种打法使用所选实力的同一移动速度、反应时间和接球半径，仍受实际触球高度、位置和被动回球质量限制；记分牌与结算显示打法，换回合和再来一局会保留选择。
- 普通/专项练习从暂停菜单退出时先显示总结，再返回模式选择或重练。比赛暂停可直接返回模式选择；比赛结算可再来一局，沿用当前模式和分值。

### 接杀与低球回球选择

比赛中接到下压、杀球、跳杀或平抽时，用原有三种操作主动选择回球：

| 回球 | 桌面操作 | 触屏按钮 | 用途 |
| --- | --- | --- | --- |
| 防守挑球 | 左键 | 选 Clear，再点大按钮（Lift） | 向上挑高，争取回位时间；轻档较浅，重档更深 |
| 挡网 | Shift＋左键 | 选 Drop，再点大按钮（Block） | 用短促动作回到对方网前，调动对手；轻档更贴网 |
| 平抽 | 低位触球时右键 | 选 Attack，再点大按钮（Drive） | 较快、较低的反击；重档更快、更深 |

球场会显示本次来球三种操作对应的回球方式，触屏按钮也会更新文字。较低的吊球、挡网来球同样支持挑球、挡网和平抽；高远与挑球来球保留原有高远、吊球、点杀/跳杀操作。接低球时，右键能否平抽取决于触球高度：球相对人物不高于 90 个逻辑高度单位时可以平抽，高位仍尝试点杀或跳杀；满足原跳杀条件时优先跳杀。球种按实际触球时的状态决定，预览使用 45 毫秒触球延迟的预测。

左右落点由鼠标或在触屏大击球按钮上左右拖动控制，力度继续用 1 / 2 / 3、滚轮或触屏力度按钮。挑球共用高远默认档，挡网共用吊球默认档，平抽共用杀球默认档；本球临时力度会同时覆盖这些回球，下一球恢复各自默认值。

三种新球路有各自的动作和瞄准颜色，平抽带紫色短拖尾。正常中档挑球约 1.57 秒、挡网约 0.72 秒、平抽约 0.50 秒；触球位置、力度和失衡状态会影响落点与越网，仍可能下网或出界。人机也能接低球挡网、挑球或平抽，并可继续进攻玩家挑出的高球。结算增加挑球、挡网、平抽次数。

接杀可以在比赛中体验，也可以进入“专项练习 → 接杀防守”单独练习。普通练习仍保留原来的高远喂球。

### 专项练习

菜单选择“专项练习”，再选练习内容、慢速 / 标准 / 快速、20 球 / 不限球数。

| 内容 | 达标目标 |
| --- | --- |
| 跳杀 | 合法完成跳杀；出现“现在起跳”时按空格，最高点附近金色提示时按右键。触屏起跳按钮会亮起 |
| 网前拦截 | 沿移动接球圈，在原落点时刻前至少 0.18 秒合法回球；球种不限，可用 Shift＋左键轻挡或吊球 |
| 接杀防守 | 合法完成挑后场、挡网或低位平抽；沿用左键 / Shift＋左键 / 右键，触屏看按钮文字 |

每种专项使用三组固定落点，成功后换下一组；未达标则重喂同组。每次喂球将人物放回固定准备位置，球速不会随着成功次数增加，不扣心，可以反复练同一个动作。20 球按尝试次数结束；不限球数可随时点球场右上方“结束并总结”，或通过暂停面板结束。

按最新反馈，恢复换人物前的杀球规则：普通跳杀在最高点附近、球绝对高度至少 75 且实际可接时成立，不再要求球高减人物跳高后达到 75。专项撤回配套加高，使用连续球路，没有接球区域的减速与水平缓动。先跑位，看到“现在起跳”按空格，随后在金色提示时按右键。在落点站定、落地前 .56 秒起跳时，慢速 / 标准 / 快速的有效右键窗口约为 0.20 / 0.165 / 0.122 秒；明显偏左的严格反手仍更难。

顶部显示达标球数、已练球数和进度。结算显示达标率、合法回球数、最长连续达标，以及跑位、时机、高度、回球选择、出界、下网六项未达标原因和针对性建议。每球只计一个主要原因；挥空后在同球补救成功不额外记失误。普通回球接住了跳杀专项来球仍算合法回球，但不算专项达标。中途结束不把尚未完成的来球算成失误；专项不会覆盖普通练习最高分。

### 按键与击球

- WASD / 方向键：在己方半场四向移动，W 向网前，S 向底线。起动需要短暂加速，松开后会刹停；高速跑动时立刻反按方向，人物会先用支撑脚减速、转移重心，再向反方向起动。站稳后换向更快，球场边线会止住惯性。
- 鼠标左右位置：连续选择回球横向落点，移动一点就会相应改变方向；鼠标上下位置不影响球的深浅。对面半场显示实际横向瞄准标记，挥拍时锁定方向，之后移动鼠标不改变已打出的球。瞄到单打边线外会显示红色“出界”提示。
- 所有来球都检查球的实时位置和高度：浅色落点圈帮助提前跑位，移动圈提示实际接球位置。高远/挑球也必须飞到人物可触及范围，站在预计落点但球还离得远时会挥空；起跳增加可触及高度，头顶击球保留少量向前伸拍的宽容度。虚线圈等待、实线圈可以挥拍、双圈最佳时机，金色提示右键跳杀。提示预估点击到触球的 45 毫秒延迟，实际触球和回球起点使用同一球位；继续跑动或临时起跳仍可能改变结果。高远/挑球保留下降阶段的击球时间窗口；低球沿路径拦截时不受原落点时刻限制，也不会被误算成早击失误。
- 挥空会区分距离太远、球还太高、球尚未进入己方、挥拍太早或太晚；重复击球会提示挥拍恢复中。提示圈的最佳时机只代表接球质量，不保证所选回球不会出界或下网。
- 当前来球的临时力度：球飞来时按数字键 1 / 2 / 3 选轻 / 中 / 重；鼠标停在球场上时，滚轮上推加一档、下推减一档。选定后，无论这一拍改打高远、吊球、点杀、跳杀、挑球、挡网或平抽，都会用同一档力度。下一次来球会自动清除临时选档，恢复该球种的默认值；挥空或漏接后的下一次来球也一样。数字键 0 或再按一次已选档位可取消当前球的临时选档。触屏点 Power 展开并选择力度，Use defaults 取消临时选档。仅在来球期间可临时调档；高远发球固定重档，小球固定轻档。
- 封面上的“游戏设置”、球场右上方的“⚙ 设置”或暂停界面的“游戏设置”，都可打开独立设置界面。可分别调整高远球、吊球和杀球的默认力度，点杀与跳杀共用杀球默认值；修改后立即生效并保存在当前浏览器。初始默认值为高远重档、吊球轻档、杀球中档。球场上会显示当前球是使用默认值还是统一临时档位，瞄准标记显示预计落点。
- 高远球轻档落在中场附近，中档较深，重档通常到达后场；吊球三档依次从贴网短球到较远的劈吊；点杀和跳杀的三档改变落点与飞行时间。球的位置、击球早晚和换重心状态也会改变实际落点，因此重档在网前或过早击球可能出界，较晚或失衡时的短吊可能下网。
- 鼠标左键：接高远/挑球时打高远球，接快攻和较低的来球时挑后场；腾空时也可主动选择左键回球。
- Shift＋鼠标左键：接高球时吊网前，接快攻和较低的来球时挡网。按住 Shift 可提前预览网前瞄准标记；使用较短的随挥和原有轻触录音。
- 空格：起跳。腾空约 0.65 秒，落地后恢复 0.18 秒；可在空中移动，按住不会连续起跳，也不能二段跳。高度越高，击球窗口越早。
- 鼠标右键 / 手机进攻按钮：较低的非高远来球可打平抽；地面正手及身体中线附近的球，实际接到就可打点杀，不再附加最低球高门槛。明显偏左的反手仍有严格条件；距离、可及高度、击球时机和越网检查仍有效。点杀中档约 0.52 秒飞向对面中后场，使用短促的下压球路、短随挥和金色拖尾，不增加跳杀奖励。球较低时先以低弧线越网再下压，避免球穿过球网。
- 起跳后右键：跳跃最高点附近、球仍足够高且位置和时机正确时，打出快速向下的跳杀；留意金色跳杀提示。不满足跳杀条件时，较低的非高远来球仍可平抽；其他来球正常接到则回退为高远球并提示原因。距离太远或时机不对仍会挥空。
- 自动反手：人物按右手持拍，实际触球时球在人物左侧就用反手，在正中或右侧用正手。左键、Shift＋左键、右键、触屏、瞄准与力度操作保持一致；高远、吊球、挑球、挡网、平抽的球路参数保持一致。提示和按钮会显示反手，人物右手跨到左侧准备、挥拍和随挥；点击后继续跑位跨过球，可以在实际触球时切回正手。
- 明显偏左的反手杀球保留换人物前的严格条件：球必须靠近左前方，人物基本停稳且没有明显换重心。反手点杀要求球高 90～120；反手跳杀要求达到最高跳跃高度的至少 95%，垂直速度在 ±55 内，球比人物腾空高度高 50～105，且高球相对接触时刻误差不超过 ±45 毫秒。身体中线左侧 .03 范围内的球，点杀和跳杀都按普通进攻条件判定，避免轻微偏左就无法进攻；仍使用实际反手动作。条件不足时右键回成反手高远，并提示“反手杀球条件不足”；低球仍可反手平抽。没有随机成功率。
- 球场内右键不会打开浏览器菜单。左键不会自动变成跳杀，同一个球可按你的选择打高远、吊球、点杀或跳杀；待发球时左键（包括 Shift＋左键）发高远球，右键发小球，方向仍限制在斜对角接发区。
- 跳杀中档回球耗时 0.32 秒，练习模式每次额外加 50 分。点杀与跳杀都会按轻 / 中 / 重档改变击球反馈：轻档依然快速，声音更清脆、闪光与金色拖尾更短更细；重档击球声更响、更厚，闪光更强、拖尾更长更宽。比赛中赢下整个回合才计 1 分。
- 人物使用分层运动造型。接球启动有小幅垫步和屈膝；侧向跑位采用较短并步，前后移动有交替步幅和抬脚，急停、反向时支撑脚撑开、上身向相反方向平衡。低球跨步跟随来球方向，击球后收回；起跳逐渐收腿，两腿有不同高度，下落伸腿，落地扩大站姿并屈膝缓冲。挥拍带转肩、上身发力、另一只手配合平衡，以及按球种区分的随挥收拍；反手右臂跨身触球，拍面朝向根据实际球位调整，减少不自然的肘部弯折。玩家与人机共用动作细节。鼠标点击后约 45 毫秒触球，球、拍面和击球特效共用触球位置；完整挥拍恢复为 0.38 秒。
- 默认人物现使用真实 3D 骨骼模型，详细说明见下方“3D 角色试玩”。不支持 WebGL 时的备用人物仍由 Canvas 实时分层绘制，其比例和服装配色集中在 `game.js` 的 `ATHLETE_BODY` / `ATHLETE_LOOKS`。当前只有默认玩家/人机两种配色，未加入角色选择菜单。实际人物预览见 `artifacts/appearance-preview.png`。
- 开局自动进入专注球场视图，收起页面标题和底部说明；返回模式选择后恢复原页面。比赛使用独立记分牌，显示双方比分、发球方、回合拍数、追分和局点（封顶前一分双方平分时显示双方局点），隐藏练习得分和最高分。
- 顶部 ? 打开操作小抄，说明按键和提示圈；游戏中打开会暂停，关闭后点击继续。⛶ 请求浏览器全屏，按钮也可退出；浏览器不支持时继续使用专注视图。力度显示改为三档短条，并标注默认、本球临时或发球固定。
- 人物新增平滑侧身、转肩、高球抬拍准备和低球跨步伸拍；随挥收回和落地衔接保留。手机竖屏保持人物、羽毛球和关键提示文字的显示比例；横屏采用紧凑记分牌与控制按钮。
- P / Esc：暂停或继续；帮助或设置打开时 Esc 先关闭面板。M：切换音效。窗口失焦自动暂停。
- 每次挥拍恢复 0.38 秒，按住鼠标左键不会自动连续挥拍；点击菜单、音效和暂停按钮不会触发挥拍。
- 无限练习，漏接、出界、下网只中断连击并记录失误，不会自动结束；Perfect 150 分，Good 100 分，每五连击增加 10 分加成，最多加 100 分。
- 每成功回球五次升一级，球速逐渐提高。前几球落点较近，后续加入网前和后场跑位，每球均留出可到达的时间。
- 结束练习时保存本地最高分；总结显示时长、已练球数、回球成功率、合法回球、漏接/出界/下网次数、最高连击、Perfect 与各种击球次数。退出按钮现在放在球场内，以更大的实色按钮显示。退出时尚未完成的来球不记为漏接；未练球也可以直接退出查看零次总结。
- 触屏设备采用左摇杆移动、右侧三种球路选择与大击球按钮；大按钮上左右拖动瞄准，松手击球，支持边移动边瞄准和击球。Jump 单独起跳，Power 按需展开。
- 击球使用四段真实羽毛球拍触球录音轮换播放，Perfect 与空中回球的力度和音高有所区别；空挥使用挥动物体的录音，起跳和落地使用木地板脚步录音。默认开启，右上角音符按钮或 M 可开关，重新开启时会试听击球声。

### 球拍外观

在“个性化 → 球拍外观”分别设置玩家、人机的球拍。可选经典椭圆、方头竞技、细长轻巧三款，以及原尺寸、加大、更大三档拍面；默认加大 16%，更大档加大 28%。拍框与手胶分别换色，拍线和装饰自动配色，近景/球场/角色预览即时更新并自动保存。“恢复默认”只恢复当前角色的球拍，不清空球衣、另一位角色、球场或落点配色。

尺寸只影响外观，实际接球范围与判定保持。九种样式/大小组合完成 486 个实际动作的拍面定位与反手避让 CPU 检查，运行 `npm run verify:rackets` 可复查；它不验证真实窗口画面或动作的主观观感。正式游戏使用运行时装备，独立角色预览与 GLB 下载保留原球拍。

仅更新角色的游戏适配时可运行 `npm run build:game-renderer`，沿用当前 GLB 和动作，再重建 Windows 游戏档案；不需要重新建模。

个性化的六处配色统一使用预设色块：米白、深黑、蓝、浅蓝、绿、橙、红、粉、紫、黄，直接点击即可应用，不再打开调色盘。“原色”恢复当前部件原配色，“自动”恢复落点/瞄准或条纹的自动搭配。选中颜色显示勾选，颜色名称代替颜色代码；之前保存的其他配色会继续保留，直到选择新的预设。
